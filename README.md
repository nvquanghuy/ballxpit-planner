# Pit Planner

A local helper for BALL x PIT ball evolutions.

1. **Directions:** tap the balls you own and pin the ones you're committed to. You get a list of curated targets, each showing what you have, what you still need, and the intermediate evolutions on the way.
2. **Breakdown:** pick a target to see the slot-safe step order, a shopping list with peak slot usage, and the recipe tree. Alternate recipes are switchable.
3. **Level-up offers:** add the balls a level-up offers you under "This level-up". The app recommends one, lists the targets each offer moves forward, and hovering (or long-pressing) an offer shows its directions. Tap "✓ took" on the one you chose: it joins your balls and the tray clears. Offers are base balls you don't own; upgrades to owned balls are ignored. Ranking: finishes a target (best tier first), then the best tier moved forward, then how many targets move forward. Plans that wouldn't fit your slots don't count.

```sh
npm install
npm run dev        # http://localhost:5173
npm test           # planner + targets.json validation
npm run sync-data  # re-snapshot balls + icons after a game patch
```

## Data

| File | Owner | What |
|---|---|---|
| `src/data/balls.json`, `public/balls/` | generated by `npm run sync-data` from [ballxpit-evolution.github.io](https://ballxpit-evolution.github.io/) | 90 balls, recipes, icons |
| `data/targets.json` | **you**: edit freely | curated targets (evolved or fused), tier S–C, why, sources |

`npm test` fails if `targets.json` names an unknown ball, lists an illegal fusion, or misses a terminal evolution.

## Rules the planner assumes

Based on [ballxpit.wiki.gg](https://ballxpit.wiki.gg/wiki/Evolution):

- Ball levels are ignored. You handle levelling; the plan only covers recipes.
- Evolution consumes all of its parts. Evolved balls can evolve again.
- Fusion combines any 2 different, unfused balls, except a pair that shares a 2-ball recipe (that pair must evolve instead).
- Owned balls the plan uses are held from the start. Owned balls it doesn't use are ignored.
- Each owned ball covers one recipe slot. Satan needs Charm twice, so owning one Charm still leaves one to find.
- You can't hold two copies of the same ball at once. A ball can be re-acquired after it's consumed.
- Missing balls are picked up just-in-time. The planner tries every recipe alternative and branch order, then picks fewest missing balls first and lowest peak slot usage second.
